# GoDrama

GoDrama is an ultra-fast, modern Flutter short drama streaming app inspired by the UI/UX architecture of JoyReels, engineered with 100% clean architecture and zero ad/tracker bloatware.

## Features
- **TikTok-style For You Feed**: Seamless vertical full-screen swipeable video player with interactive action bar.
- **Dynamic Home Experience**: Hero carousel slider, category horizontal tabs, and responsive staggered card layout.
- **Dedicated Player Screen**: Built-in video player with floating episode bottom sheet drawer, auto-next, and resolution controls.
- **Pure Vector Assets & Typography**: Official Urbanist typography (Thin to Black) and SVG vector icons.
- **Zero Bloatware**: No ad mediation SDKs, no spyware/trackers, pure clean 60-120 FPS rendering.

## Getting Started
```bash
flutter pub get
flutter run
```
